기능 범위

MESA International의 11대 기능모델을 뼈대로 잡고, 국내 현장에서 실제로 쓰는 용어로 화면을 구성했습니다. 표준 용어를 그대로 번역해서 메뉴에 걸면 현장에서 아무도 누르지 않는다는 게 1차 구축 때의 교훈입니다.

M-01 / M-02

생산 모니터링 · 작업지시

ERP 생산오더를 받아 작업지시로 확정하고, 라인별 진척과 계획 대비 실적을 실시간으로 표출합니다. 현장 대형 모니터 상시 표출용 자동 갱신을 지원합니다.

MESA-11 ③ 작업단위 배정 / ⑪ 성과분석
M-03 / M-04

작업배정 · POP 현장단말

설비 단위 간트로 일정을 배정하고, 현장 단말에서 자재 확인 → 셋업 체크 → 작업 시작 → 실적 등록까지 한 화면에서 처리합니다. 오투입 시 다음 단계로 넘어가지 않습니다.

MESA-11 ① 상세일정 / ⑤ 데이터수집 / ⑥ 인력관리
M-05

설비관리 · OEE

시간가동률 × 성능가동률 × 양품률로 OEE를 자동 산출합니다. 비가동 사유는 TPM 6대 로스 기준 12종으로 통합했고, MTBF·MTTR과 예방보전 일정을 함께 관리합니다.

MESA-11 ② 자원상태 / ⑨ 설비보전
M-06

품질관리 · SPC

X-bar / R 관리도와 공정능력지수 Cp·Cpk를 산출하고, 관리이탈 룰(3σ 이탈, 연속 7점 편향)을 자동 판정합니다. 중결함 발생 시 다음 공정 진행을 차단합니다.

MESA-11 ⑦ 품질관리 / IATF 16949 에러프루핑
M-07

배치 · 레시피 (ISA-88)

마스터 레시피에서 컨트롤 레시피를 인스턴스화해 배치를 실행합니다. 페이즈별 설정값과 실적값을 트렌드로 비교하고, 전자배치기록(EBR)으로 감사추적을 남깁니다.

ISA-88 Part 3 레시피 / Part 4 EBR
M-08 / M-09

LOT 추적 · 성과분석

완제품에서 원료까지 역방향, 원료에서 출하처까지 정방향 계보를 트리로 조회합니다. 리콜 영향범위 산출까지 포함해 고객사 감사 대응 시간을 단축합니다.

MESA-11 ⑩ 제품추적·계보 / ⑪ 성과분석

시스템 아키텍처

ISA-95(IEC 62264) 계층 모델을 기준으로 위치를 정의했습니다. SH-MES는 Level 3에 해당합니다.

Level 4
SH-ERP — 전사적자원관리수주 · 생산계획(MRP) · 구매 · 재고 · 원가 · 회계
Level 3
SH-MES — 제조실행시스템 (본 시스템)작업지시 · 실적 · 품질 · 설비 · LOT 계보 · 배치 실행
Level 2
SH-FMS — 통합 모니터링 / SCADA실시간 공정 감시 · 알람 · 트렌드 · CCTV
Level 1/0
PLC · 센서 · 설비LS XGT / Mitsubishi MC Protocol / Modbus TCP → OPC UA 게이트웨이

기술 사양

  • 화면 HTML5 / CSS / Vanilla JS — 외부 CDN 의존 없음(폐쇄망)
  • 차트 자체 SVG 구현 (라인·막대·도넛·게이지·관리도)
  • 대상 해상도 현장 패널PC 1280×800 고정
  • 인증 역할기반 접근제어(RBAC), 실적 수정 시 변경이력 기록
  • API REST + JSON, 필드명은 B2MML 어휘 준수
