## 1. 요구사항 식별 체계

`SH-MES-REQ-nnn` 형식. 출처는 다음 셋 중 하나다.

- **(조사)** 사전조사 보고서 SH-PRE-2026-001 의 해당 항목번호
- **(자체)** 국내 MES/POP 공급사 기능 소개자료 및 공개 사례 조사
- **(법규)** IATF 16949 등 외부 요구

## 4. 인터페이스 요구사항

| ID | 방향 | 대상 | 내용 | 주기 |
|---|---|---|---|---|
| IF-01 | 수신 | SH-ERP | 생산오더 | 10분 |
| IF-02 | 수신 | SH-ERP | 품목마스터 / BOM / 거래처 | 일 1회 + 변경 시 |
| IF-03 | 송신 | SH-ERP | 생산실적 (양품/불량) | 실적 등록 즉시 |
| IF-04 | 송신 | SH-ERP | 자재투입실적 | 배치/작업 종료 시 |
| IF-05 | 수신 | 설비 PLC | 가동상태, 생산카운터, 공정값 | OPC UA 구독 1초 |
| IF-06 | 양방향 | SH-FMS | 설비 상태·알람 공유 | 실시간 |

API 필드명은 B2MML 어휘를 준수한다 (예: `ProductionRequest`, `SegmentResponse`, `MaterialLot`).
정식 B2MML XML 구현은 2차 과제로 이월하고, 1차는 REST + JSON 으로 구현한다.

## 5. 제외 범위

- 공정 시뮬레이션 / 디지털 트윈
- 설비 원격제어 (모니터링만 수행, 제어는 SCADA 권한)
- 원가 계산 (SH-ERP 담당)
- 창고 로케이션 관리 (SH-ERP WMS 모듈 담당)
