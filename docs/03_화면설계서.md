# SH-MES 화면설계서

| 항목 | 내용 |
|---|---|
| 문서번호 | SH-MES-UI-2026-001 |
| 프로젝트 | 프로젝트SH (개인 프로젝트) |
| 작성 | 남성흠 |
| 버전 | Rev.3 (2026-09-22) |
| 기준 해상도 | 1280 × 800 (현장 패널PC) / 1920 × 1080 (사무) |

## 1. 공통 레이아웃

```
┌──────────┬──────────────────────────────────────────────────┐
│  브랜드   │  화면명 · 화면번호        교대조 · 시계 · 사용자   │  52px
├──────────┼──────────────────────────────────────────────────┤
│          │                                                  │
│  좌측    │                  본문 영역                        │
│  메뉴    │                  (스크롤)                         │
│  208px   │                                                  │
│          │                                                  │
└──────────┴──────────────────────────────────────────────────┘
```

- 좌측 메뉴는 `현장 운영 / 설비·품질 / 추적·분석` 3개 그룹
- 상단바 우측에 사업장·교대조 표시. 교대 기준은 08:00~20:00 A조, 그 외 B조
- 공통 틀은 `assets/js/shell.js` 가 렌더. 페이지는 `<body data-page data-title data-crumb>` 만 지정

## 2. 색 체계

ISA-101 고성능 HMI 원칙에 따라 **정상 상태는 무채색, 색은 이상 상태에만** 사용한다.

| 용도 | 색상 | 값 |
|---|---|---|
| 배경 | 다크 네이비그레이 | `#0f1419` |
| 패널 | | `#171d26` |
| 강조(브랜드) | 틸 | `#00a9a5` |
| 정상 / 가동 | 그린 | `#46c46b` |
| 경고 / 셋업 | 앰버 | `#e0a83a` |
| 이상 / 정지 | 레드 | `#e5544b` |
| 정보 | 블루 | `#3d8bfd` |
| 대기 / 비활성 | 그레이 | `#4d5a6e` |

> 다크 테마를 쓴 이유: 야간조에서 밝은 화면이 눈부시다는 컴플레인이 1차 시스템 운영 중 반복 접수됨.

## 3. 화면별 설계

### M-01 생산 모니터링

| 영역 | 구성 |
|---|---|
| 상단 | KPI 5종 — 계획대비 달성률 / 금일 생산량 / 불량률 / 종합 OEE / 가동설비 |
| 좌중단 | 시간대별 생산량 (계획 vs 실적 꺾은선, 영역 채움) |
| 우중단 | 종합 OEE 반원 게이지 + A/P/Q 분해 |
| 중단 | 라인별 진척 현황 테이블 (상태 배지, 진척 바, 설비별 OEE) |
| 하단좌 | 불량 유형 파레토 (상위 3종 적색 강조) |
| 하단우 | 실시간 이벤트 로그 (최근 60분, 스크롤) |

- 30초 자동 갱신. 현장 대형 모니터 상시 표출 대응
- 이벤트 로그는 심각도별 색 구분 (설비정지=적, 품질이상/자재부족=황, 일반=청)

### M-02 작업지시 관리

| 영역 | 구성 |
|---|---|
| 필터 | 사업장 / 라인 / 상태 / 품번 + 조회·초기화 + ERP 수신·일괄확정 |
| 요약 | 조회 건수 / 총 지시수량 / 진척률 / 불량수량 |
| 목록 | 체크박스, 지시번호, ERP 오더, 품번·품명, 라인, 수량, 진척 바, 상태, 납기, 담당 |
| 상세 | 행 클릭 시 인라인 확장 — 공정경로(라우팅), 생산 LOT, 잔량 |

- 납기 경과 건은 납기일에 적색 + ⚠ 표시
- 라우팅은 완료(녹)/진행(틸)/대기(회) 3단계로 구분

### M-03 작업배정 · 디스패칭

| 영역 | 구성 |
|---|---|
| 필터 | 기준일 / 교대조 / 배정 규칙(EDD·FIFO·셋업최소화) + 자동배정 실행 |
| 요약 | 평균 부하율 / 배정 작업시간 / 셋업 손실시간 / 과부하 설비 수 |
| 간트 | 설비(행) × 08:00~20:00(열). 작업=틸, 셋업=앰버, 현재시각=적색 수직선 |
| 하단좌 | 미배정 작업지시 목록 + 행별 배정 버튼 |
| 하단우 | 설비 부하율 막대 (100% 초과 적색) |

### M-04 POP 현장단말 (3열 구성)

```
┌───────────────┬────────────────────────┬───────────────┐
│ 작업지시 정보  │    작업 제어           │ 공구·금형 수명 │
│               │    ├ 경과시간 타이머    │               │
│ ① 투입자재    │    ├ 작업시작 (56px)   │ 작업표준서     │
│   LOT 스캔    │    └ 일시정지 / 종료   │               │
│               │                        │ 4M 변경점      │
│ ② 셋업        │ ③ 실적 등록           │               │
│   체크리스트   │    양품/불량 + 키패드  │               │
└───────────────┴────────────────────────┴───────────────┘
```

**진행 게이트** — ①과 ② 가 모두 완료되어야 `작업시작` 버튼이 활성화된다.
미등록 LOT 스캔 시 적색 경고와 함께 해당 자재는 확인 처리되지 않는다.

**터치 규격** — 주요 조작 버튼 최소 높이 56px, 보조 버튼 44px, 키패드 40px.

### M-05 설비관리 · OEE

| 영역 | 구성 |
|---|---|
| 좌상 | 종합 OEE 게이지 (목표선 85%) |
| 우상 | A / P / Q / 가동·정지 KPI |
| 중단 | 설비 상태 보드 — 카드형 4열. 좌측 3px 리본으로 상태 표시 |
| 하단좌 | 6대 로스 막대 (최대 항목 적색) |
| 하단우 | 비가동 사유 파레토 |
| 최하단좌 | MTBF / MTTR + OEE 스파크라인 |
| 최하단우 | 예방보전 일정 (경과/임박/예정) |

### M-06 품질관리 · SPC

| 영역 | 구성 |
|---|---|
| 상단 | Cp / Cpk / 규격 / 판정 |
| 좌중 | X-bar 관리도 — UCL·CL·LCL(황) + USL·LSL(적) 기준선 |
| 우중 | 관리이탈 판정 결과 + 적용 룰 안내 |
| 하단좌 | R 관리도 |
| 하단우 | 측정값 히스토그램 (규격 이탈 구간 적색) |
| 최하단 | 검사 실적 / 부적합(NCR) 처리 현황 |

### M-07 배치 · 레시피

| 영역 | 구성 |
|---|---|
| 상단 | 배치 카드 4열 — 페이즈 진행 바(7단계) + 온도/압력/RPM 현재값 |
| 좌중 | 배치 트렌드 — 온도(실제 vs 설정) + 교반 RPM 2단 차트 |
| 우중 | 전자배치기록(EBR) — 시각 / 수행자 / 행위 / 내용 |
| 하단좌 | 마스터 레시피 목록 (승인/폐기) |
| 하단우 | 레시피 상세 — 포뮬러 표 + 절차 표 |

### M-08 LOT 추적 · 계보

| 영역 | 구성 |
|---|---|
| 필터 | LOT 번호 입력 + 방향 토글(역방향/정방향) + 리콜 산출 / 보고서 출력 |
| 요약 | 추적 노드 수 / 추적 단계 / 품질이상 노드 / 출하 수량 |
| 좌 | 계보 트리 — 들여쓰기 + 연결선. 노드 = 공정태그 · LOT · 설비·작업자 · 수량 · 일시 |
| 우 | LOT 기본정보 / 출하 이력 / 연관 품질기록 |

- 품질 이상 이력 노드는 적색 테두리 + `품질이상` 태그
- 원자재 노드는 별도 배경으로 구분

### M-09 성과분석 리포트

| 영역 | 구성 |
|---|---|
| 필터 | 기간 / 집계기준(라인·품목·작업조) + 엑셀·인쇄 |
| 상단 | KPI 5종 |
| 중단좌 | 일별 생산량 + 불량률 2단 차트 |
| 중단우 | OEE 구성요소(A/P/Q) 추이 |
| 하단좌 | 집계 테이블 (합계 행 포함, OEE 스파크라인) |
| 하단우 | 4M 불량 원인 도넛 |
| 최하단 | 개선 과제 현황 |

## 4. 공통 컴포넌트

| 컴포넌트 | 클래스 | 용도 |
|---|---|---|
| KPI 타일 | `.kpi` | 좌측 3px 리본으로 상태(`k-ok`/`k-warn`/`k-bad`) 표시 |
| 카드 | `.card` + `header` + `.body` | 모든 패널의 기본 |
| 테이블 | `.tb` | 헤더 고정색, 숫자열 `.num` 은 모노스페이스 우정렬 |
| 상태 배지 | `.st` + `st-run/idle/stop/set/done` | 색 규칙 통일 |
| 진행 바 | `.mini-bar` | 진척률 / 부하율 / 공구수명 |
| 필터 바 | `.filters` | 모든 목록 화면 상단 |
| 주석 | `.note` | 좌측 선 + 회색 소문자. 화면 하단 설명 |
