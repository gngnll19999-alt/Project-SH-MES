## 1. 요약

화성1공장 제조실행시스템 재구축 과제의 화면 개발이 완료되었다.
9개 업무 화면 전체가 구현되었고, 남은 일정은 ERP·설비 연계 검증과 현장 병행운영이다.

이번 과제의 핵심은 기능을 늘리는 것이 아니라 **끊어진 데이터 흐름을 잇는 것**이었다.
구체적으로 세 가지를 잡았다.

1. 배합(화학) 라인이 엑셀 배합지시서로 돌아 LOT 추적이 끊기던 문제 → ISA-88 레시피 구조 도입
2. OEE를 월말에 수기 집계하던 문제 → 실적·비가동 데이터 기반 실시간 산출
3. 고객사 품질감사 시 계보를 2~3일간 수작업으로 만들던 문제 → 계보 트리 자동 조회

## 3. 사전조사 결과와 설계 반영

조사 대상은 네 갈래였다.

| 갈래 | 대상 |
|---|---|
| 국제 기능표준 | MESA-11, ISA-95, ISA-88, ISA-101, ISA-18.2 |
| 글로벌 패키지 | SAP S/4HANA, Siemens Opcenter Execution, Rockwell Plex MES |
| 국내 패키지 | 더존 iCUBE, 영림원 K-System, 이카운트, 미라콤 Nexplant MESplus |
| 국내 법규·제도 | IATF 16949, HACCP, 스마트공장 수준확인 |

총 100건 중 MES 반영분은 40건이고, 5건은 2차 과제로 이월, 2건은 제외했다.
(상세: `00_사전조사_벤치마킹_100건.md`)

**설계에 가장 크게 영향을 준 조사 항목 3가지**

1. **Plex MES 작업자 컨트롤 패널** (조사 #18)
   자재확인 → 품질 셋업체크 → 공수 기록 → 공구수명 확인 → 실적/수율 → SPC 라는 동선이
   이미 현장에서 검증된 순서였다. POP 화면을 이 순서 그대로 배치했고, 여기에 4M 변경점만 추가했다.

2. **ISA-101 고성능 HMI** (조사 #63~71)
   "정상 상태는 무채색, 색은 이상 상태에만" 이라는 원칙. 1차 시스템은 상태별로 색을 다 넣어서
   화면이 알록달록했는데, 정작 이상이 생겨도 눈에 안 띄었다. 이번에 색 사용을 대폭 줄였다.

3. **ISA-88 레시피 4계층** (조사 #87)
   General / Site / Master / Control 중 당사는 단일 사업장이므로 Master / Control 2단만 사용하기로 했다.
   4계층을 다 넣으면 관리 부담만 커진다.
